常见问题

我的笔记存在哪里？会不会丢？

所有笔记都以 HTML 文件保存在软件旁的「笔记」文件夹里，随时可以整文件夹备份或使用软件内置备份功能。复制整个软件文件夹就是完整备份。

AI 功能怎么用？要额外花钱吗？

在 AI 助手设置里填入你自己的 API Key 即可。费用由对应 AI 服务商按用量收取，与三叶草无关；不填 Key 也能正常当记事本用。

新建/重命名时输入框突然打不出字怎么办？

偶尔会遇到输入法尚未就位的情况，直接关闭软件重新打开即可，笔记不会丢失。

为什么激活码换电脑不能用？

激活码绑定单台电脑的硬件信息，用于防止拷贝转卖。换电脑后联系作者，提供新机器码即可免费重新激活一次。

有手机版吗？

目前只有 Windows 电脑版；安卓 / iOS 版本正在规划中，上线后会在这里和软件内同步公告。
